# ระบบสหกรณ์โรงเรียน — LINE LIFF + Supabase + Netlify

เว็บแอปจัดการรายรับ-รายจ่ายสหกรณ์โรงเรียน เปิดใช้งานผ่าน **LINE** โดยตรง (ไม่ต้องสมัครสมาชิก
ไม่ต้องจำรหัสผ่าน) — ครูเปิด LINE → กดลิงก์/เมนู → เจอฟอร์มบันทึกรายรับ-รายจ่ายทันที
ข้อมูลถูกเก็บใน Supabase และไฟล์ทั้งหมดเป็น static (HTML+CSS+JS) deploy ขึ้น Netlify ได้เลย

## วิธีทำงาน (สรุปสั้น ๆ)
ครูเปิดลิงก์ `https://liff.line.me/{LIFF_ID}` จาก LINE → แอปรู้จักตัวตนจากบัญชี LINE ทันที
(ผ่าน LIFF SDK) → ถ้าเป็นการเปิดครั้งแรก ระบบจะสร้างบัญชีในตาราง `users` ให้อัตโนมัติ
(**คนแรกที่เปิดแอปจะได้สิทธิ์ผู้ดูแลระบบโดยอัตโนมัติ** คนถัดไปได้สิทธิ์ "ผู้บันทึก" แล้วให้แอดมิน
ไปปรับสิทธิ์ทีหลังได้) จากนั้นเข้าหน้า Dashboard ได้เลย ไม่มีหน้าล็อกอิน ไม่มีรหัสผ่านให้ลืม

## ไฟล์ในชุดนี้
- `index.html` — ตัวเว็บแอปทั้งหมด (LIFF login, dashboard, ฟอร์มรายรับ/รายจ่าย, รายการ, หมวดหมู่, รายงาน, ผู้ใช้งาน)
- `schema.sql` — คำสั่งสร้างตาราง, Row Level Security, storage bucket, และหมวดหมู่เริ่มต้น
- `netlify/functions/line-webhook.js` — รับข้อความจากแชท LINE แล้วแปลงเป็นรายการบันทึกอัตโนมัติ
- `netlify.toml` — บอก Netlify ว่าโฟลเดอร์ฟังก์ชันอยู่ที่ไหน
- `README.md` — ไฟล์นี้

## ขั้นตอนที่ 1: ตั้งค่า Supabase
1. สร้างโปรเจกต์ใหม่ที่ https://supabase.com
2. ไปที่ **SQL Editor** วางเนื้อหาในไฟล์ `schema.sql` ทั้งหมด แล้วกด Run
   - จะได้ตาราง `users` (คีย์คือ LINE userId), `categories`, `transactions`, `attachments`
   - สร้าง storage bucket ชื่อ `slips` (public) สำหรับเก็บรูปสลิป/ใบเสร็จ
   - ใส่หมวดหมู่เริ่มต้นให้อัตโนมัติ
3. ไปที่ **Project Settings > API** คัดลอกค่า `Project URL` และ `anon public API key`

## ขั้นตอนที่ 2: Deploy เว็บขึ้น Netlify (ทำก่อน เพื่อจะได้ URL ไปใช้สร้าง LIFF)
1. เปิดไฟล์ `index.html` แก้ 2 บรรทัดนี้ก่อน:
   ```js
   const SUPABASE_URL = "https://YOUR-PROJECT.supabase.co";
   const SUPABASE_ANON_KEY = "YOUR-PUBLIC-ANON-KEY";
   ```
   (`LIFF_ID` ยังไม่ต้องใส่ตอนนี้ รอขั้นตอนที่ 3)
2. ไปที่ https://app.netlify.com/drop ลากโฟลเดอร์ที่มี `index.html` วางลงไป
3. จะได้ URL เว็บไซต์ เช่น `https://your-site.netlify.app` — **เก็บ URL นี้ไว้ใช้ในขั้นตอนถัดไป**

## ขั้นตอนที่ 3: สร้าง LINE LIFF App (ยังไม่มี ต้องสร้างใหม่)
1. ไปที่ https://developers.line.biz/console/ แล้วล็อกอินด้วยบัญชี LINE (คนละบัญชีกับที่ใช้แชทได้)
2. ถ้ายังไม่เคยมี **Provider** ให้กด "Create" ตั้งชื่อ Provider (เช่น ชื่อโรงเรียน)
3. ในหน้า Provider กด **"Create a new channel"** เลือกประเภท **"LINE Login"**
4. กรอกข้อมูลช่อง (Channel name, Channel description, Category/Subcategory เลือกใกล้เคียงที่สุด, Email) แล้วกดสร้าง
5. เข้าไปในช่องที่สร้าง ไปที่แท็บ **"LIFF"** กด **"Add"** เพื่อสร้าง LIFF app:
   - **LIFF app name**: เช่น "สหกรณ์โรงเรียน"
   - **Size**: Full
   - **Endpoint URL**: URL จาก Netlify ในขั้นตอนที่ 2 (เช่น `https://your-site.netlify.app`)
   - **Scope**: ติ๊ก `profile` และ `openid`
   - **Bot link feature**: ปล่อยเป็น Off ก็ได้ (ไม่จำเป็นต้องมีบอทแชท)
   - กด Add
6. จะได้ **LIFF ID** หน้าตาประมาณ `1234567890-AbCdEfGh` — คัดลอกไว้

## ขั้นตอนที่ 4: ใส่ LIFF ID แล้ว deploy ซ้ำ
1. เปิด `index.html` อีกครั้ง ใส่ค่าที่ได้ในบรรทัดนี้:
   ```js
   const LIFF_ID = "YOUR-LIFF-ID";
   ```
2. ลากไฟล์ขึ้น Netlify ซ้ำอีกครั้ง (หรือถ้าต่อ Git ไว้ก็แค่ commit + push)

## ขั้นตอนที่ 5: เปิดใช้งานจริงผ่าน LINE
- แชร์ลิงก์ `https://liff.line.me/{LIFF_ID}` (เอา `{LIFF_ID}` เป็นค่าที่คัดลอกไว้) ในกลุ่ม LINE ของครู หรือ
- ผูกลิงก์นี้ไว้กับปุ่มใน Rich Menu ของ LINE Official Account (ถ้ามี) เพื่อให้กดเข้าแอปได้จากเมนูโดยตรง
- คนแรกที่กดลิงก์นี้เข้าแอป **จะกลายเป็นผู้ดูแลระบบโดยอัตโนมัติ** ทันที ไม่ต้องตั้งค่าอะไรเพิ่ม

**หมายเหตุการทดสอบ:** ลิงก์ `liff.line.me/...` ต้องเปิดผ่านแอป LINE (บนมือถือ) เท่านั้นถึงจะทำงานได้ครบ
ถ้าเปิดในเบราว์เซอร์ธรรมดาบนคอมพิวเตอร์ LIFF SDK จะพยายามพาไปหน้าล็อกอิน LINE ผ่านเว็บแทน ซึ่งใช้ทดสอบได้เช่นกัน

## ขั้นตอนที่ 6 (ใหม่): พิมพ์ในแชท LINE แล้วบันทึกอัตโนมัติ
นอกจากเปิดฟอร์มในแอปแล้ว ตอนนี้พิมพ์ข้อความคุยกับ LINE Official Account ของโรงเรียนได้เลย
ระบบจะอ่านข้อความแล้วบันทึกเป็นรายการให้อัตโนมัติ พร้อมตอบกลับยืนยัน

**รูปแบบข้อความที่พิมพ์ได้:**
- รายรับ: `รับ 500 ขายน้ำ` หรือ `รายรับ 500 ขายน้ำ` หรือ `+500 ขายน้ำ`
- รายจ่าย: `จ่าย 320 ซื้อสมุด` หรือ `รายจ่าย 320 ซื้อสมุด` หรือ `-320 ซื้อสมุด`
- ระบบจะพยายามจับคู่คำในข้อความกับหมวดหมู่ที่มีอยู่ให้อัตโนมัติ (เช่นถ้ามีหมวดหมู่ชื่อ "ซื้อสินค้า" ข้อความ "จ่าย 320 ซื้อสินค้า สมุด" จะถูกจัดเข้าหมวดนั้นให้)
- คนที่สิทธิ์ยังเป็น **"ผู้ตรวจสอบ" (ดูอย่างเดียว)** จะพิมพ์บันทึกไม่ได้ ระบบจะตอบกลับให้ไปขอสิทธิ์จากแอดมินก่อน

**ตั้งค่า (ทำครั้งเดียว):**
1. กลับไปที่ Provider เดียวกับที่สร้าง LIFF channel ไว้ในขั้นตอนที่ 3 (**ต้องเป็น Provider เดียวกัน** ไม่งั้น LINE userId จากแชทจะไม่ตรงกับตอนเปิดผ่าน LIFF)
2. กด **"Create a new channel"** เลือกประเภท **"Messaging API"** กรอกข้อมูลช่อง (ชื่อ, คำอธิบาย, หมวดหมู่, อีเมล) แล้วสร้าง
3. ในช่องที่สร้าง ไปแท็บ **"Basic settings"** คัดลอก **Channel secret**
4. ไปแท็บ **"Messaging API"** เลื่อนลงไปกด **"Issue"** ที่ช่อง Channel access token (long-lived) คัดลอกค่าไว้
5. ในหน้าเดียวกัน ตั้งค่า **Webhook URL** เป็น `https://your-site.netlify.app/.netlify/functions/line-webhook` แล้วกด **"Verify"** (ตอนนี้ยังไม่ผ่านก็ไม่เป็นไร ยังไม่ได้ตั้งค่าตัวแปรใน Netlify) เปิดสวิตช์ **"Use webhook"** เป็น On
6. ไปที่ **LINE Official Account Manager** (https://manager.line.biz) เลือกบัญชีเดียวกันนี้ > **Settings > Response settings** ปิด **"Auto-reply messages"** และ **"Greeting messages"** ทั้งคู่ (ไม่งั้นบอทจะตอบข้อความอัตโนมัติแข่งกับระบบของเรา)
7. ที่ Netlify > **Site configuration > Environment variables** เพิ่ม 4 ตัวแปร:
   - `LINE_CHANNEL_SECRET` = ค่าจากข้อ 3
   - `LINE_CHANNEL_ACCESS_TOKEN` = ค่าจากข้อ 4
   - `SUPABASE_URL` = อันเดียวกับใน `index.html`
   - `SUPABASE_SERVICE_ROLE_KEY` = Supabase > Project Settings > API > `service_role` `secret` key (**ห้ามใส่ใน index.html เด็ดขาด**)
8. กด **Trigger deploy > Deploy site** อีกครั้งให้ Netlify โหลดตัวแปรใหม่
9. กลับไปที่ Messaging API channel กด **Verify** อีกครั้งที่ Webhook URL ให้ขึ้นสำเร็จ
10. สแกน QR code ของบัญชี (อยู่ที่แท็บ Messaging API เช่นกัน) เพื่อเพิ่มบอทเป็นเพื่อนใน LINE แล้วลองพิมพ์ `รับ 100 ทดสอบ` ดูได้เลย

## ระดับความปลอดภัยที่เลือกใช้ในเวอร์ชันนี้
เลือกแบบ **เร็ว/ง่ายก่อน**: ไม่มีเซิร์ฟเวอร์กลางตรวจสอบตัวตนจาก LINE ก่อนบันทึกข้อมูล — เว็บคุยกับ
Supabase ตรง ๆ ด้วย anon key และเชื่อว่าใครก็ตามที่เปิดแอปผ่านลิงก์ LIFF ได้คือคนใน LINE กลุ่มนั้นจริง ๆ

**ข้อควรรู้:** เพราะไม่มีการตรวจสอบระดับฐานข้อมูล คนที่คัดลอก anon key จากหน้าเว็บไปเรียก Supabase
API ตรง ๆ จะอ่าน/แก้ไขข้อมูลได้โดยไม่ผ่านการตรวจสิทธิ์ เหมาะกับกลุ่มที่ไว้ใจกัน (ครูในโรงเรียนเดียวกัน)
ถ้าในอนาคตอยากให้ปลอดภัยขึ้น สามารถเพิ่ม Netlify Function หรือ Supabase Edge Function ที่ตรวจสอบ
LINE ID token (ผ่าน `https://api.line.me/oauth2/v2.1/verify`) ก่อนอนุญาตให้บันทึก/แก้ไขข้อมูลได้ทีหลัง
โดยไม่ต้องรื้อโครงสร้างเดิม — บอกมาได้เลยถ้าอยากให้ทำส่วนนี้เพิ่ม

## ฟีเจอร์ที่ทำไว้ในเวอร์ชันนี้
- เปิดแอปผ่าน LINE แล้วรู้จักตัวตนทันที (ชื่อ + รูปโปรไฟล์) ไม่ต้องสมัคร ไม่ต้องมีรหัสผ่าน
- ผู้ใช้ใหม่ถูกเพิ่มเข้าระบบอัตโนมัติเมื่อเปิดแอปครั้งแรก คนแรกสุดได้สิทธิ์ผู้ดูแลระบบอัตโนมัติ คนถัดไปเริ่มต้นเป็น "ผู้ตรวจสอบ" (ดูได้อย่างเดียว) จนกว่าแอดมินจะเลื่อนสิทธิ์ให้
- แอดมินปรับสิทธิ์ผู้ใช้คนอื่น (ผู้ดูแลระบบ/ผู้บันทึก/ผู้ตรวจสอบ) และ**ลบผู้ใช้งาน**ได้จากเมนู "ผู้ใช้งาน" (ลบแล้วรายการเก่าของคนนั้นยังอยู่ครบ แค่ไม่ผูกชื่อผู้บันทึกแล้ว)
- **พิมพ์บันทึกรายการผ่านแชท LINE ได้เลย** เช่น "รับ 500 ขายน้ำ" หรือ "จ่าย 320 ซื้อสมุด" — ระบบตอบกลับยืนยันทันที (เฉพาะผู้ที่มีสิทธิ์ผู้บันทึกขึ้นไป)
- ผู้ใช้แก้ไขชื่อที่แสดงในระบบของตัวเองได้ที่หน้า "ตั้งค่า" (รูปโปรไฟล์ sync จาก LINE อัตโนมัติทุกครั้งที่เปิด)
- Dashboard: รายรับ-รายจ่ายวันนี้, คงเหลือสะสม, กราฟแท่งสรุปเดือน, รายการล่าสุด (อัปเดตแบบ Realtime)
- ฟอร์มเพิ่มรายรับ/รายจ่าย พร้อมแนบไฟล์สลิป/ใบเสร็จ (jpg/png/pdf) ขึ้น Supabase Storage
- ตรวจจับรายการซ้ำอัตโนมัติ (เตือนเมื่อพบรายการหน้าตาคล้ายกันในช่วง 2 ชั่วโมงล่าสุด)
- ตารางรายการทั้งหมด ค้นหา/กรองตามวันที่ ช่วงวันที่ หมวดหมู่ ผู้บันทึก และจำนวนเงิน
- ดูรูปสลิปแบบ popup พร้อมดาวน์โหลด
- จัดการหมวดหมู่รายรับ/รายจ่าย
- รายงานตามช่วง (วันนี้/สัปดาห์/เดือน/ปี/กำหนดเอง) พร้อม Export เป็น Excel และพิมพ์/บันทึกเป็น PDF
- พิมพ์ใบสำคัญรับ-จ่ายเงินรายรายการ พร้อม QR code สำหรับให้ผู้ตรวจสอบสแกนดูหลักฐาน

## ส่วนที่ยังไม่รวมไว้ (ต้องพัฒนาเพิ่มถ้าต้องการ)
- **OCR อ่านสลิปอัตโนมัติ**: ต้องเชื่อมบริการ AI/OCR ภายนอก แล้วนำผลลัพธ์มาเติมในฟอร์มอัตโนมัติ
- **ตรวจสอบตัวตนจาก LINE ฝั่งเซิร์ฟเวอร์**: ตามที่อธิบายไว้ในหัวข้อความปลอดภัยด้านบน
- **แนบรูปสลิปผ่านแชท LINE**: ตอนนี้พิมพ์บันทึกยอดเงิน+รายละเอียดผ่านแชทได้ แต่การแนบรูปสลิปยังต้องทำผ่านฟอร์มในแอป (LIFF) เท่านั้น
